# Food Frenzy - Fast Food Restaurant POS System

A desktop Point of Sale (POS) and billing application developed using **C#** and **Windows Forms (.NET Framework)** in Microsoft Visual Studio.

---

## 🍽️ Features

- **Main Items Ordering:** Dynamic quantity selection and automated subtotal calculation for main dishes (Sandwiches, Burgers, Fried Chicken, Hot Dogs, Pizzas).
- **Sides & Beverages:** Selection of side dishes (French Fries, Onion Rings, Salads, Potato Wedges) and drinks.
- **Smart Billing & Balance Estimation:** Automated total bill computation, cash tendered input, and instant change/balance calculation.
- **Receipt Workflow:** Integrated receipt generation for customer transactions.

---

## 🛠️ Tech Stack

- **Language:** C#
- **Framework:** .NET Framework (Windows Forms)
- **IDE:** Microsoft Visual Studio
- **Architecture:** Event-Driven GUI Application

---

## 🚀 Getting Started

### Prerequisites
- Windows OS
- Microsoft Visual Studio (2015 or newer) with .NET desktop development workload

### Running the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/fashfa026-ctrl/Food-Frenzy-POS.git
   ```
2. Open `Fast Food Resturant.sln` in Visual Studio.
3. Build and run the project (`F5` or click **Start**).
